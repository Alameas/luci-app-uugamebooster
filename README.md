# luci-app-uugamebooster

适用于 OpenWrt 和 ImmortalWrt 的 UU 主机加速插件

## 支持架构

- aarch64
- armhf
- mipsel_24kc

## 功能

- 同时加速多个设备
- 切换设备类型
- 查看设备状态
